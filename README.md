# AutoDS - Autonomous Data Scientist

AutoDS is an autonomous AI-powered Data Science platform designed to automate data exploration, analysis, modeling, and reporting.

## Project Structure

```
AutoDS/
├── .agents/
│   └── rules/
│       └── agents.md          # Permanent AI engineering rules
├── docs/
│   ├── PRD.md                 # Product Requirements Document
│   ├── ARCHITECTURE.md        # System Architecture & Tech Stack
│   ├── ROADMAP.md             # Development Roadmap & Milestones
│   ├── API_SPEC.md            # API Specifications
│   ├── DATABASE.md            # Database Schemas & Migrations
│   └── DECISIONS.md           # Architecture Decision Records (ADR)
├── frontend/                  # Next.js, React, Tailwind, TypeScript
├── backend/                   # FastAPI, Python 3.12, Pydantic v2, SQLAlchemy 2, Alembic
└── docker/                    # Docker & Compose configurations
```

## Tech Stack

- **Frontend**: Next.js, React, Tailwind CSS, TypeScript
- **Backend**: FastAPI, Python 3.12, Pydantic v2, SQLAlchemy 2, Alembic
- **Infrastructure**: Docker, Docker Compose
